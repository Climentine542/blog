这是一篇展示格式的示例笔记，不是个人经历。静态博客把内容和页面结构分开：写作时只需要维护文字，统一排版由模板处理。

## 写、预览、构建

1. 写一份 Markdown：标题和日期供目录使用，正文供详情展示。
2. 在浏览器预览：确认目录能点进来，正文里的图片和链接也可以访问。
3. 到发布前再构建：输出目录保存的是生成出来的网页，不是日常写作的位置。

![一册打开的笔记与页角小圆点](/media/articles/notebook.svg)

## 两条常用命令

```bash
npm run dev
npm run build
```

两条命令用途不同：前者边写边看，后者生成静态产物。想看 Astro 对静态渲染的说明，可以打开 [Astro 文档](https://docs.astro.build/)。
